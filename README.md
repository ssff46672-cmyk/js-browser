# JS Browser

**JS Browser** is a free online code editor for writing, testing, and learning HTML, CSS, and JavaScript directly in your browser.

## Features

- Write HTML, CSS, and JavaScript online.
- Run code and preview the results.
- Experiment with web development projects.
- Learn through built-in code examples.
- Practice web development without installing an editor.
